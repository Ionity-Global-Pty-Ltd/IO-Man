Install guide (HOW_TO_INSTALL.txt)

Install

  1. Download TheValley_Setup.exe (above) and run it - it downloads and installs everything. About 55 GB free is needed (an SSD is best).
  2. Double-click The Valley.exe. Windows SmartScreen may warn (the game is not code-signed yet): More info → Run anyway.
  3. Pick a World Server and press PLAY ON SERVER. On the title screen REGISTER or LOG IN, forge your champion and ENTER THE VALLEY.
