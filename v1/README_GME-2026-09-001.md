## What it is

A single-file HTML5 canvas arcade rendered entirely as a 112×30 character terminal grid in the Ionity ANSI palette (cyan `#00c6ff`, dark `#0d1b2a`, LGREEN/ORANGE/RED/PURPLE from the AEDI shell scripts). No images, no external assets, no network. Open `IONITY_GET_OVER_IT_DOOR.html` in any modern browser.

The arena is the ASCII layout from the design brief: TIME and GOVERNANCE bars on top, starfield, stepped `====` platforms, the `GET OVER IT DOOR` box on a central platform, and the ground line carrying `| HP 100% |` with the `+++++` tail.

## Loop

Evil mushrooms walk in from the left and right, parachute in from the top, and pop out of the ground. Chop the stage quota, the door unlocks, climb the platforms (get over it), walk into the door, next stage.

## Controls

Move `A`/`D` or arrows · Jump `W`/`↑`/`Space` · Chop `J`/`X`/`F` · Pause `P` · Mute `M` · Start/skip `Enter` · Restart `R` (end screens). Touch buttons appear on coarse-pointer devices.

## DTA (run data)

Every run records chops, hits, accuracy, jumps, kills per type, damage taken, heals, coins, max combo, per-stage time/kills/damage/score, and the build block. Shown on the pause, game-over and victory screens; export as JSON via COPY / DOWNLOAD. Best run is kept in browser localStorage (`ionity_god_best`) when available.
